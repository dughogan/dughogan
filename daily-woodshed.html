    How the rotation works. One tune a day, drawn from a 24-song book in a shuffled no-repeat cycle — you see everything before you see anything twice. Each pass through the book comes back under a different lens (Changes, Riff, Solo, Jam), so a repeat is a new assignment, not a rerun. Everything you mark or type stays in this browser.

    On the tabs. Figures are labelled: PART is my transcription of the actual part; STYLE is a line written in that player's vocabulary over the real changes; DRILL is an exercise built from the tune's key and technique. Charts marked verify are my best read of the harmony — trust the record over me. Goose cards are ear-first by design: that catalog is thinly tabbed, so the first job is finding the key yourself, which is how the band learned it too.
